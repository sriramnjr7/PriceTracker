# QA Verification Skill

When testing a target URL or feature flow:

1. **Navigate & Inspect**: Load the target URL or run the CLI check command.
2. **Verify Elements**: Confirm price, title, stock status, and formatting.
3. **Edge Cases**: Test with out-of-stock items, discounted items, and multi-currency formats.
4. **Report**: Summarize test status (Passed / Failed / Warning) with exact output logs.
