# YC Office Hours Skill

When invoked, run through the 6 core forcing questions before writing any code:

1. **Demand Reality**: Who desperately wants this right now? What are they doing today instead?
2. **Status Quo**: Why hasn't this been solved? What is the friction with existing solutions?
3. **Desperate Specificity**: What is the single exact user persona and scenario for the first release?
4. **Narrowest Wedge**: What is the absolute smallest slice of functionality that delivers real value?
5. **Observation**: What counter-intuitive insight did you notice from real usage?
6. **Future-Fit**: How does this scale or evolve into a durable feature/product?

### Execution:
- Present the 6 questions concisely.
- Help the user answer and summarize the conclusions into a clear spec doc before implementation.
