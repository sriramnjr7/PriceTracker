# CEO Plan Review Skill

When invoked, challenge the current feature proposal across 4 scope modes:

1. **The 10x Simplification**: What is the single most valuable 10% of this feature that delivers 90% of the value? Can we cut the rest?
2. **User Friction Check**: Where will the user get stuck, confused, or frustrated?
3. **Failure Mode Analysis**: What happens if the network drops, the target site blocks us, or the database is locked?
4. **Scope Freeze**: Lock down the minimal viable deliverable and eliminate scope creep.
